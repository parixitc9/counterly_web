Install

Four steps to your first bill.

  1. 01

    Run the installer

    Choose the install folder. A desktop shortcut is created for you.

  2. 02

    Allow it

    If Windows shows "Windows protected your PC", click More info, then Run anyway.

  3. 03

    Activate

    Copy the Hardware ID, get a key, and paste it in.

  4. 04

    Set up your shop

    Save your shop name and address in Settings, then add products. Full guide.

Check the file

Make sure it's the real installer.

The installer isn't code-signed yet, so Windows can't vouch for it. You can still check it yourself by comparing its SHA-256 fingerprint with the one published here.

Open PowerShell and run this, changing the path if you saved the file somewhere else:

Get-FileHash "$env:USERPROFILE\Downloads\Counterly.Setup.1.0.7.exe"

The Hash it prints must match exactly:

DB84DFD3DEF3526FF3566D7BF806813DCB97D455B2CC67AFFEC5774CB16E3539

If it doesn't match, don't run the file. Download it again from this page and tell us.

Updating

Install over the top. Keep everything.

  • Close Counterly first, then run the new installer.
  • Your records stay. Products, stock, customers, bills, shop details and your license are kept.
  • Upgrades run once. On first start, the database is upgraded automatically, in one step.
  • No automatic updates. Counterly doesn't update itself. New versions are listed below.

Release notes

What changed, version by version.

  1. Version 1.0.7 20 October 2026 · Latest

    GST tax invoices, loose goods, corrections and data safety.

    • GST tax invoices. HSN/SAC and GST rate per product, GST % per bill line, CGST + SGST in-state and IGST for buyers in other states, "Tax Invoice" title, place of supply and "Page x of y".
    • Sell by weight, volume or length. Quantities with up to three decimals, with exact FIFO costing.
    • USB barcode scanners. An exact SKU match is added and the search clears for the next scan.
    • Cancel a wrong bill. With a reason. The number stays, stock returns to its lots, and reports leave it out.
    • Backup and data. Daily backups to Documents\Counterly Backups (14 kept), backup status with warnings, and CSV export.
    • Export without a license. "Export my records" on the activation screen.
    • Faster at scale. Sales history no longer grows with every bill. Tested at 1,00,000 bills.
    • Clearer messages. Database, activation and WhatsApp errors now say what to do.
    • Fixes. Invoice date follows the clock past midnight, billing waits for shop details, and a new key clears a clock-ahead lockout.

  2. Version 1.0.6 October 2026

    Invoices on WhatsApp and email.

    • Automatic sending. After checkout, invoices go out through the shop's own SMTP account and WhatsApp Business Platform sender.
    • A safe queue. Limited retries, an Unknown state that waits for you to confirm, and no resending of accepted invoices.
    • Consent. WhatsApp sending needs the customer's recorded agreement.
    • Encrypted credentials. Passwords and tokens are stored with Windows secure storage and never shown again.

  3. Version 1.0.5 October 2026

    A clean way to start over.

    • Clear this workspace. In Settings, type ERASE ALL to remove all records and the activation. A recovery backup is made first.

  4. Version 1.0.4 7 October 2026

    A security and reliability review across ten areas.

    • Security. Trusted-window checks on every internal request, and the invoice renderer blocks outside files.
    • Licensing. Small clock corrections no longer cause false lockouts, and malformed keys are rejected.
    • Stock and checkout. Purchase costs on every receipt, stricter cash and total checks, and safe rollback.
    • Reports. Loading errors no longer look like zero sales, and profit uses historical costs.
    • Clean installs. The installer carries no records, keys or databases, and updates keep your data.
